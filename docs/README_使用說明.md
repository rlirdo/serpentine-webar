# 墨玉晶格修復任務 WebAR — 使用說明（2.0 語音版）

版本 2.0.0（2026/10/02）。2.0 新增**語音導覽**：遊戲裡的對話、提示、測驗題目與選項都會唸出來，玩家可以邊聽邊玩。1.0 版的檔案仍然保留，可以照舊使用。

- 線上遊戲網址：<https://rlirdo.github.io/serpentine-webar/>
- 原始碼（GitHub）：<https://github.com/rlirdo/serpentine-webar>

用手機掃描「任務卡」，主角「墨玉小晶」就會浮現在卡片上方，帶你闖過蛇紋石材料實驗的八個步驟。整個遊戲約 8–10 分鐘，有前測 3 題、後測 5 題和行動承諾。

## 語音導覽（2.0 新增）

- **會唸什麼**：小晶的對話、每關開場與提示、答對答錯的回饋、學習重點與環境小語、工作假設提醒、測驗題目和四個選項（「A、…；B、…」）、答題詳解、結果頁的星數與恭喜。按鈕上的字、進度條、製作者字樣不唸。
- **化學符號會改成中文唸**：例如 Mg²⁺ 唸「鎂離子」、Fe³⁺ 唸「鐵離子」、DSW 唸「深層海水」、FTIR 逐字母唸「F T I R」、50 °C 唸「50 度」、4–14 微米唸「4 到 14 微米」。畫面上的文字不變。
- **開關**：遊戲畫面右上角的〔語音開〕按鈕，按一下變成〔語音關〕，再按一下恢復。旁邊的🔊是音效（叮咚聲）開關，兩個分開控制。設定會記在這台裝置的瀏覽器裡。
- **再聽一次**：點一下對話框裡的文字，就會重唸一次。
- **第一句可能不會唸**：手機和電腦的瀏覽器規定，使用者要先點過畫面，網頁才能發出語音。所以開場第一句通常不會唸；按〔下一步〕之後就會開始唸。想聽第一句，可以點一下對話文字。
- **不用等唸完**：可以隨時按下一步，舊的語音會停掉，改唸新的內容。切到別的 App 或關掉頁面時，語音也會停止。
- **手機音量**：語音走的是「媒體音量」，請把媒體音量調大。iPhone 側邊的靜音鍵一般不會擋住語音合成，但仍請確認音量不是 0（不同 iOS 版本可能不同，沒有聲音時請把靜音鍵撥回響鈴）；Android 請確認不是「勿擾」或媒體靜音。
- **多人同桌**：好幾支手機一起唸會互相干擾，可以每組只開一支的語音，其他人按〔語音關〕，或戴耳機。
- **沒有中文語音的裝置**：語音用的是裝置內建的中文語音（例如 Windows 的 Microsoft Hanhan／Yating／Zhiwei、iPhone 與 Android 內建的國語語音），不需要下載，也不會把文字傳到我們的伺服器。如果裝置沒有中文語音，右上角會出現一次「此裝置沒有中文語音，請看文字」，遊戲照常進行，只是不會唸。
  - Windows 可到「設定 → 時間與語言 → 語音 → 新增語音」加入「中文（台灣）」。
  - 瀏覽器只有雲端的中文語音時（例如沒有安裝中文語音的電腦上的 Chrome「Google 國語（臺灣）」），會改用它，這時需要網路才唸得出來。

## 三種玩法

### 玩法一：教室投影（exe 啟動器＋學生手機掃描）

適合全班一起玩。老師的電腦要能接投影機；學生手機要能上網。

1. 把 `墨玉晶格修復任務WebAR_v2.exe` 複製到教室電腦（放桌面或隨身碟都可以，不用安裝）。
2. 點兩下執行。第一次執行時如果出現藍色的「Windows 已保護您的電腦」（SmartScreen），請按「**其他資訊**」，再按「**仍要執行**」。
3. 瀏覽器會自動打開「全班開始畫面」：左邊是大張任務卡，右邊是 QR 碼和三個步驟。同時會出現一個小控制視窗（標題有「2.0（語音版）」）。
4. 學生用手機掃畫面上的 QR 碼，打開線上網址 → 按〔開始 AR（開相機）〕→ 允許使用相機 → 把手機對準投影上的任務卡。
5. 下課時按控制視窗的〔結束遊戲〕，或直接關閉控制視窗。這樣遊戲伺服器就會停止，不會留在背景執行。

說明：

- 學生手機是連到上面的**線上網址**（HTTPS），不是連到老師的電腦，所以學生手機一定要能上網；老師的電腦不需要網路。
- 開始畫面下方的按鈕：
  - 〔電腦直接玩〕：不需要手機或網路，在電腦上直接玩。
  - 〔用這台電腦的鏡頭玩 AR〕：使用筆電或視訊鏡頭，把紙本任務卡拿到鏡頭前面。
  - 〔全螢幕任務卡〕：按 Esc 可以離開全螢幕。
  - 〔列印任務卡 PDF〕
  - 〔教師頁〕
- 不小心關掉瀏覽器時，按控制視窗的〔重新開啟頁面〕就能再打開。

### 玩法二：只用手機（開網址＋紙本任務卡）

不需要電腦。

1. 把 `墨玉晶格修復任務卡_列印用.pdf` 印出來。印的時候選「**實際大小／100%**」，卡片寬度是 12 公分。也可以用另一台平板或手機顯示 `墨玉晶格修復任務卡.png`。
2. 手機掃紙上的 QR 碼，或直接輸入網址：<https://rlirdo.github.io/serpentine-webar/>
3. 按〔開始 AR（開相機）〕→ 允許相機 → 對準任務卡。
4. 沒有任務卡時，可以在首頁按〔沒有任務卡：直接玩〕。

### 玩法三：電腦直接玩（免相機、免網路）

- 用 exe：點兩下執行後，在開始畫面按〔電腦直接玩（免手機、免網路）〕。整個遊戲都在這台電腦上執行，完全不用網路。
- 有網路時，也可以用瀏覽器直接打開 <https://rlirdo.github.io/serpentine-webar/play.html>。

## 相機權限

- 手機第一次按〔開始 AR〕時，瀏覽器會詢問「是否允許使用相機」，請按「**允許**」。
- 如果不小心按了「封鎖」：
  - **iPhone（Safari）**：在網址列點「大小」或「ᴀA」圖示 →「網站設定」→ 把「相機」改成「允許」，再重新整理頁面。也可以到「設定 → Safari → 相機」修改。
  - **Android（Chrome）**：點網址列左邊的圖示 →「權限」或「網站設定」→ 把「相機」改成「允許」，再重新整理頁面。
- 請用手機內建的瀏覽器（iPhone 用 Safari，Android 用 Chrome）。LINE、Facebook 等 App 裡面的瀏覽器常常無法開相機，請點右上角選單，選「用瀏覽器開啟」。
- 遊戲的相機畫面只在手機上辨識任務卡，不會錄影，也不會上傳。

## 常見問題

**Q1：掃不到任務卡，小晶一直沒出現？**

- **亮度**：環境要夠亮；如果用螢幕顯示任務卡，請把螢幕亮度調高。
- **反光**：投影幕、螢幕或亮面紙容易反光。請稍微換一個角度，避開燈光直射的位置。
- **距離**：手機離紙本任務卡約 **20–40 公分**。如果是對準投影，請往前或往後移動，讓任務卡在手機畫面裡夠大。
- **大小**：讓任務卡大約**佔手機畫面的一半**，而且整張卡片都要在畫面裡。
- 手要拿穩，先停 1–2 秒。小晶出現後，就算卡片跑出畫面，遊戲也會改成「懸浮模式」繼續玩。

**Q2：手機掃了 QR 碼，可是網頁打不開？**

手機要能上網。學校的 Wi-Fi 如果需要登入，請先完成登入，或改用行動網路。

**Q3：exe 點兩下沒有反應，或被防毒軟體擋下來？**

這個 exe 沒有數位簽章，所以第一次執行時 Windows 會出現 SmartScreen 警告，請按「其他資訊 → 仍要執行」。如果學校電腦禁止執行 exe，可以改用玩法二或「玩法三」的線上 play.html。

**Q4：要用哪個網址才能看到作答紀錄？**

作答紀錄只存在「作答的那台裝置、那個瀏覽器」裡面。

- 用手機玩：在同一支手機打開〔教師頁〕，或請學生把結果頁截圖。
- 用 exe 玩：2.0 版的紀錄存在 `http://127.0.0.1:8732` 這個網址下面（1.0 版是 `8731`）。請固定用同一台電腦、同一個瀏覽器。開始畫面的〔教師頁〕可以匯出 CSV。

1.0 和 2.0 用不同的埠，所以兩版可以同時開著不會衝突，但**兩版的教師頁紀錄是分開的**：用 1.0 玩的紀錄要在 1.0 的教師頁看，用 2.0 玩的要在 2.0 的教師頁看。如果 8732 埠被其他程式占用，exe 會改用其他埠，這時候就看不到先前的紀錄。

**Q5：會蒐集學生的個資嗎？**

不會。遊戲不問姓名或學號，作答結果只存在該裝置，不會上傳；也沒有任何追蹤或分析程式。

**Q6：exe 的進階參數？**

這些參數給技術人員用，一般使用者不需要：

- `--selftest`：自我檢查。結果寫在 exe 旁邊的 `墨玉晶格修復任務WebAR_v2_selftest.log`；如果那個資料夾不能寫入，就改寫到 `%TEMP%\serpentine-webar-v2\`。
- `--no-browser`：不自動開瀏覽器。
- `--port N`：指定埠（預設 8732）。
- `--version`：顯示版本。

執行紀錄寫在 `%TEMP%\serpentine-webar-v2\launcher.log`。
